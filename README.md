# Projeto-da-Disciplina-IA
Projeto de IA para geração automática de resumos financeiros
# Dataset Utilizado

Este projeto utiliza dados provenientes do **EDGAR (Electronic Data Gathering, Analysis, and Retrieval)** da **SEC (Securities and Exchange Commission)**. O conjunto de dados inclui relatórios financeiros anuais (10-K) e trimestrais (10-Q) de empresas do setor tecnológico nos últimos 5 anos, totalizando aproximadamente 100 documentos.

## Conteúdo:
- Demonstrações Financeiras
- Relatórios da Administração
- Notas Explicativas
